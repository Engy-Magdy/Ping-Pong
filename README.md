## ✨ Features

* **Object-Oriented Design (OOP):** Built using clean, modular classes for the Ball, Paddles, and Scoreboard (`ball.py`, `paddle.py`, `score.py`, `main.py`).
* **Smooth Controls & Physics:** Responsive paddle movements and dynamic ball collision mechanics.
* **Live Scoring System:** Keeps track of each player's score in real-time.
* **Standalone Executable:** Compiled into a clean `.exe` file with a custom application icon (`favicon.ico`) using PyInstaller, running seamlessly without needing a console window.

---

## 🛠️ Tech Stack & Concepts

* **Language:** Python 3.12
* **Library:** Pygame (or Turtle/Tkinter depending on your core implementation)
* **Version Control:** Git & GitHub
* **Tooling:** PyInstaller (for compilation)
